SAVEURS PRESTIGE — SITE WEB PREMIUM
=================================

1) Ouvrez le dossier dans VS Code.
2) Ouvrez index.html dans votre navigateur (ou utilisez l'extension Live Server).
3) Dans script.js, remplacez 2126XXXXXXXX par le vrai numéro WhatsApp de Chef Soukaina.
   Format : indicatif pays + numéro, sans le signe +. Exemple fictif : 2126XXXXXXXX.
4) Les photos sont dans assets/. Vous pouvez remplacer les images en gardant les mêmes noms.
5) Les produits et descriptions sont illustratifs : confirmez le vrai catalogue, les tarifs et les photos avec la cliente.

FICHIERS
- index.html : structure du site
- style.css  : design responsive et animations
- script.js  : menu mobile, animations au scroll, WhatsApp

Le site utilise Google Fonts via Internet. Les autres fichiers sont locaux.
